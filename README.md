# Iceworld_Game_Demo
Demo olarak Claude AI ile geliştirilmiş Tarayıcıda çalışan, Counter-Strike'tan esinlenen Iceworld temalı 3D FPS. Botlara karşı oyna, takım arkadaşı ekle, 8 farklı silah kullan. Kurulum yok, tek HTML dosyası.

## Özellikler
- 3 harita: Iceworld, Buz Arena, Gece Kampı
- Ayarlanabilir rakip (1-12) ve takım arkadaşı (0-6) sayısı
- 8 silah: Bıçak, Pompalı, AK-47, Bomba, M4A1, MP4, AWP, Desert Eagle
- Haritadan silah ve zırh toplama
- Buz zemin fiziği (kayma), kar yağışı
- Ana menü ve ayarlar (fare hassasiyeti, FOV)

## Kontroller
| Tuş | İşlev |
|---|---|
| WASD | Hareket |
| Fare | Bakış |
| Sol tık | Ateş / vur / bomba at |
| Sağ tık | AWP dürbünü |
| Shift | Koş |
| Boşluk | Zıpla |
| R | Şarjör değiştir |
| F | Sonraki silah |
| 1-8 | Silahı doğrudan seç |

## Çalıştırma
`index.html` dosyasını tarayıcıda aç ya da GitHub Pages ile yayınla.

> Bu proje hayran yapımı bir demodur; Valve veya Counter-Strike ile bağlantısı yoktur.
